# iPad / 手机中文聊天

游戏内置聊天框走的是英文键位，拼音输入法打不进去。

## 1. iPad 先加中文键盘
设置 → 通用 → 键盘 → 键盘 → 添加键盘 → 简体中文 → 拼音。
屏幕左下角地球键里要能看到「简体拼音」。你截图里只有 English 和阿拉伯语。

## 2. 接到 mc.cq.je
把 `cn-chat.js` 放到站点目录，游戏页 `</body>` 前：
```html
<script src="/cn-chat.js"></script>
```
屏幕下方会出现输入框，用中文键盘打字，点「发送」。

若发送后游戏里仍是空的，说一声，改成由服务器插件转发。
